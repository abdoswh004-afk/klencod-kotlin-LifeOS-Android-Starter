# Life OS — Android

مشروع أولي لتطبيق Android أصلي لإدارة الحياة، باستخدام Kotlin وJetpack Compose.

## الوضع الحالي
هذه **نسخة تأسيسية أولية** وليست التطبيق النهائي. تحتوي على:
- مشروع Android أصلي قابل للفتح في Android Studio.
- واجهة عربية داكنة RTL.
- لوحة رئيسية ومساحات أولية للأقسام.
- إعداد Gradle واعتماديات Compose الأساسية.

الأقسام المخطط لها:
1. الرئيسية  2. المهام  3. العادات  4. المالية  5. الأهداف
6. التقويم  7. الصحة  8. التعلّم  9. المذكرات  10. المشاريع
11. الأعمال  12. التحليلات  13. المعرفة  14. الإعدادات

## متطلبات البناء
- Android Studio حديث
- JDK 17
- Android SDK 35
- اتصال إنترنت أول مرة لتنزيل Gradle والاعتماديات

## فتح المشروع
1. فك ضغط الملف.
2. افتح Android Studio.
3. اختر Open ثم اختر مجلد `LifeOS-Android`.
4. انتظر Gradle Sync.
5. من القائمة Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).

## خارطة الطريق
- المرحلة 1: تثبيت أساس المشروع والتحقق من البناء.
- المرحلة 2: التنقل الكامل وتصميم كل شاشة.
- المرحلة 3: قاعدة بيانات محلية Room وعمليات الإضافة والتعديل والحذف.
- المرحلة 4: المهام والعادات والمالية والأهداف.
- المرحلة 5: بقية الوحدات والتقويم والإشعارات.
- المرحلة 6: النسخ الاحتياطي والحماية والاختبارات.

## مبدأ الخصوصية
الهدف أن يعمل التطبيق محلياً دون اشتراط حساب سحابي. لن نضيف مزامنة أو إرسال بيانات إلى خادم دون قرار واضح.
